# Music and Sound Effects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The game plays flight music and a sound for each event of a game, generated in the
browser, with one switch that silences everything and is remembered between visits.

**Architecture:** A new `js/sound.js` holds the tune as data, pure helpers, and the `APN.sound`
object that owns the Web Audio API. `js/ui.js` only notifies it of events and renders the switch.
The music is scheduled note by note a little ahead of time, so its speed can change from the next
note and it can stop at once.

**Tech Stack:** Plain JavaScript (no build, no dependencies), Web Audio API, `localStorage`,
`node --test` for unit tests, Playwright for browser tests.

**Spec:** `docs/specs/2026-11-17-sound-design.md`. Read it first: the tune, the effect recipes
and the table of moments and sounds are there and are not repeated here.

## Global Constraints

- No sound files and no new dependency; the game still works by opening `index.html` from disk.
- Code, comments, test names and commit messages are in English; everything the player reads or
  a screen reader announces is in Spanish.
- `js/sound.js` follows the pattern of `js/game-logic.js`: an IIFE that extends
  `globalThis.APN` and ends with the `module.exports = APN` guard, so it loads under Node.
- No method of `APN.sound` ever throws: not when sound is off, not without `AudioContext`, not
  before the first tap, not under Node.
- `js/ui.js` calls `APN.sound.<method>(...)` at the moment of each event and never keeps a
  reference to a method, so the browser tests can replace the methods to record the calls.
- A wrong answer or a level that is not passed never sounds like a punishment.
- The owner's name is never written in any file or commit message: say "the owner".
- Implementers never discard work (`git checkout .`, `restore`, `reset --hard`, `stash`,
  `clean`); a task that cannot be finished is reported as BLOCKED with the exact reason.
- Unit tests: `node --test tests/*.test.js`. Browser tests: `npx playwright test`
  (`--project=desktop` or `--project=phone`). Both must pass at the end of every task.

## Review Focus

Conditions the spec implies and a player will meet; each is pinned by the named test.

1. The browser has no `AudioContext` at all: the whole game plays with no page error (Task 4,
   "a whole game without AudioContext raises no page error").
2. `localStorage` throws or holds a value that is neither `on` nor `off`: sound is on and nothing
   is reported (Task 1, the `loadSoundChoice` and `saveSoundChoice` tests).
3. The switch is tapped many times quickly during the music: no page error and the last tap wins
   (Task 3, "ten quick taps on the switch leave it in the state of the last tap").
4. A second game is started while music is playing ("Jugar otra vez", or `startMusic` twice): one
   `stopMusic` silences it (Task 2, "starting the music twice still stops with one stop").
5. The page is hidden in the middle of a trip and shown again: sound is suspended, then resumes
   (Task 2, "hiding the page suspends the sound and showing it resumes it").

### Task 1: Tune data, pure helpers and the remembered choice

**Files:**
- Create: `js/sound.js`
- Test: `tests/sound.test.js`

**Interfaces:**
- Consumes: nothing.
- Produces, all on `APN`:
  - `SOUND_KEY = 'apn.sound'`, `MUSIC_BEAT_SECONDS = 0.24`, `MUSIC_TURBO_BEAT_SECONDS = 0.20`,
    `TAKE_OFF_SECONDS = 1.1`, `TURBO_SOUND_DELAY_SECONDS = 0.5`.
  - `SOUND_NAMES`: the array `['tap', 'takeOff', 'deliver', 'express', 'turbo', 'arrive',
    'storm', 'reindeer', 'drop', 'pass', 'notPassed']`.
  - `FLIGHT_TUNE = { beatsPerBar: 4, melody: [[name, beats], ...], bass: [name, ...] }`, with the
    values of the spec's "The tune" verbatim.
  - `noteFrequency(name: string): number`. Equal temperament, `A4` = 440 Hz. Throws
    `Error('Unknown note: <name>')` for anything that is not a letter `A`-`G` followed by one
    digit.
  - `tuneEvents(tune): { totalBeats: number, events: Array<{ beat: number, voice: 'melody' |
    'bass' | 'bell', frequency: number, beats: number, accent: boolean }> }`, sorted by `beat`.
    Melody: one event per note, at the running sum of the beats before it. Bass: per bar, the
    note at beat 0 of the bar and the same note at 1.5 times the frequency at beat 2, each 1.6
    beats long. Bell: one per beat, `beats` 0, `accent` true on even beat numbers (0, 2, ...).
    `totalBeats` is `bass.length * beatsPerBar`.
  - `loadSoundChoice(storage): boolean` and `saveSoundChoice(storage, on: boolean): void`, where
    `storage` has `getItem` and `setItem`. Only the stored value `'off'` means `false`.

  - `noteFrequency rejects a name that is not a note`: `'H4'`, `'E'` and `''` each throw
    `Unknown note: <name>`.
  - `the flight melody fills its 16 bars exactly`: the sum of the melody beats equals

  - `every note of the flight tune has a valid name`: `noteFrequency` accepts every melody and

  - `tuneEvents lists 51 melody notes, 32 bass notes and 64 bells in beat order`: the counts per
    voice, `totalBeats` 64, and `events` sorted by `beat`.
  - `tuneEvents places the bass on beats 1 and 3 of each bar, the second a fifth higher`: for bar
    0, events at beat 0 (`C3`) and beat 2 (1.5 times `C3`), each 1.6 beats.
  - `the sound choice is on unless the stored value is off`: `loadSoundChoice` returns `true`

    `saving the sound choice ignores a storage that throws`.

### Task 2: The sound engine

**Files:**
- Modify: `js/sound.js`, `index.html` (add `<script src="js/sound.js"></script>` between
  `js/game-logic.js` and `js/ui.js`), `e2e/helpers.js`
- Test: `tests/sound.test.js`, `e2e/sound.spec.js` (create)

**Interfaces:**
- Consumes: everything Task 1 produces.
- Produces `APN.sound`:
  - `isOn(): boolean`. Initial value: `APN.loadSoundChoice(localStorage)`; `true` where there is
    no `localStorage`.
  - `toggle(): boolean`. Flips the state, saves it with `saveSoundChoice`, returns the new
    state. Turning off silences music and effects within 0.1 s and stops the music. Turning on
    creates or resumes the `AudioContext` (it is called inside a tap) and plays nothing.
  - `play(name: string, delaySeconds = 0): void`. Plays the recipe of the spec's "The effects"
    for `name`. Does nothing for a name outside `APN.SOUND_NAMES`.
  - `startMusic(delaySeconds = 0): void`. Plays `APN.FLIGHT_TUNE` from its first note, looping,
    at the current speed. If music is already playing or waiting to start, it is replaced, never
    doubled.
  - `stopMusic(): void`. Silence within 0.1 s; also cancels a start that is still waiting.
  - `setTurbo(on: boolean): void`. Chooses `MUSIC_TURBO_BEAT_SECONDS` or `MUSIC_BEAT_SECONDS`.
    Remembered even while no music plays. While music plays, applies from the next note that has
    not been scheduled yet, without restarting the tune.
  - `state(): { on: boolean, music: boolean, turbo: boolean, context: 'none' | 'suspended' |
    'running' | 'closed' }`. `music` is `true` from `startMusic` until `stopMusic` or a toggle to
    off. For tests and debugging.
  - `play`, `startMusic` do nothing when sound is off or there is no `AudioContext`; `setTurbo`
    and `stopMusic` always update the state. The `AudioContext` is created on the first `play`,
    `startMusic` or `toggle` to on, and resumed there if suspended.
- Produces in `e2e/helpers.js`: `openGame(page)` (routes the analytics script and opens the
  game, without clicking anything; `startGame` now calls it) and `recordSounds(page)` (replaces
  `play`, `startMusic`, `stopMusic` and `setTurbo` on `APN.sound` with wrappers that push
  `[method, ...args]` to `window.__soundCalls` and still call the original; returns nothing).

**Behaviour:**
- Scheduler: a timer every 25 ms schedules every event of `APN.tuneEvents(APN.FLIGHT_TUNE)` whose
  start falls within the next 0.2 s of the context's clock, wrapping to the first event after
  the last. An event's time is `anchorTime + (event.beat - anchorBeat) * beatSeconds`. On
  `setTurbo` the anchor moves to the next unscheduled event (its beat, and its time under the
  old speed) before the speed changes; on wrapping, `anchorBeat` drops by `totalBeats`.
- Voices: melody is a triangle wave, bass a sine wave, the bell a very short high square tick,
  louder when `accent`. Each note has a 15 ms attack and fades to silence over its length; a
  melody note sounds for 92 % of its length.
- Music goes through its own gain, lower than the effects', so an effect is heard over it.
- When `document.hidden` becomes true (`visibilitychange`) the context is suspended; when it
  becomes false and sound is on, it is resumed.

**Behaviour**, the calls `js/ui.js` makes, in this order within each function:

| Where | Calls |

| `deliver` | `play(r.express ? 'express' : 'deliver')`; if `r.turbo`, `play('turbo', APN.TURBO_SOUND_DELAY_SECONDS)` |
| `fail` | `play(mishap.id)` (the ids are `storm`, `reindeer`, `drop`) |
| `showResult` | `stopMusic()`, then `play(r.passed ? 'pass' : 'notPassed')` |
